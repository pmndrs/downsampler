Mip chain for a texture

A procedural rgba8unorm image is uploaded to level 0, and Downsampler writes every other level with compute shaders. The default odd-size policy, 'exact', gives the same result as render-pass (and WebGL) mipmaps: each level is checked below against the library's CPU reference, computed from the GPU's own previous level. Switch to 'spd' to see AMD SPD's semantics (two dispatches at most sizes, the last odd row or column dropped), and toggle the tail kernel to see the dispatch count change. 

const downsampler = new Downsampler( device );
downsampler.encode( encoder, texture );                      // levels 1 … n from level 0
downsampler.encode( encoder, texture, { oddSizes: 'spd' } ); // SPD semantics (average only)
