Custom reduction with Reducer: block statistics

A Reducer runs one tile kernel that reduces up to six levels in workgroup memory and stores only the levels you ask for. Here a load hook reads the tool's own texture (in @group(1)) and returns, per texel, (luma, luma², luma, 1). The channels reduce as [ 'average', 'average', 'max', 'sum' ], so each output texel of level 3 (8 × 8 blocks) and level 5 (32 × 32 blocks) holds the block's mean luma, mean of squares, maximum and texel count: enough for a mean, a standard deviation and a peak per block, in one dispatch.

Edges are 'zero-weight' (the default): blocks that reach past the image count only their in-image texels, and level sizes round up (⌈n / 2ˡ⌉), so the outputs are separate textures rather than mips of the source. The readout compares every emitted texel with reducePyramid, the CPU oracle, computed straight from the source. 

const stats = new Reducer( device, {
	reduction: [ 'average', 'average', 'max', 'sum' ],
	levels: [ 3, 5 ],
	format: 'rgba32float',
	bindings: { wgsl: '@group(1) @binding(0) var image: texture_2d<f32>;', entries },
	load: `fn load( texel: vec2i, layer: u32 ) -> vec4f {
		let l = dot( textureLoad( image, texel, 0 ).rgb, vec3f( 0.2126, 0.7152, 0.0722 ) );
		return vec4f( l, l * l, l, 1.0 );
	}`,
} );
stats.encode( encoder, { width, height, bindGroup, outputs: [ level3, level5 ] } );
