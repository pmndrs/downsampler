downsampler examples

Small, dependency-free pages (plain ES modules that import the built library from ../dist/). Each one explains what it does and checks its own output on the page: a readout of PASS lines compares the GPU's results with the library's CPU oracles. Run them with npm run examples, which builds and serves the repository at http://localhost:8080/examples/. WebGPU needs a secure context: localhost, or HTTPS on other devices.

  • Mip chain
    Every level of a texture from level 0, with a level viewer; 'exact' vs 'spd' odd sizes and the tail kernel.
  • Hi-Z from depth
    A (min, max) pyramid from a depth buffer through a separate source, recorded with encodePass; conservativeness checked.
  • Block statistics (Reducer)
    A load hook and per-channel ops: mean, variance, max and count per 8² and 32² block, in one dispatch.
  • Exposure (ScalarReduction)
    Log-average luminance of an HDR frame in two dispatches, with a finish hook that computes the exposure on the GPU.
  • three.js
    downsampler/three mipmaps a StorageTexture, side by side with three's own render-pass mipmaps. Loads three from a CDN.

Usage guide: docs/guide.md. Coming from SPD: docs/spd-users.md.
