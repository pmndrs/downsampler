ScalarReduction: average luminance and exposure

ScalarReduction reduces a whole image to one vec4f (and a weight) in two dispatches at any size: per-workgroup partials, then one workgroup combines them. Every texel counts once; no edge row or column is dropped and nothing is limited to a power-of-two window.

The first reduction meters a 1920 × 1080 rgba16float HDR frame for auto exposure: a load hook returns (log luma, luma, luma, luma), reduced per channel as [ 'average', 'max', 'min', 'average' ], and a finish hook, run once on the GPU, turns the log average into an exposure (0.18 / geometric mean) and stores it in the tool's own buffer, where a tone-mapping pass could read it the same frame. The second reduction has no hooks at all: it averages the texture's colour into an output buffer. Move the slider: the scene gets brighter, the exposure drops, and the tone-mapped image (drawn on the CPU here with the GPU's exposure) stays about the same. 

const metering = new ScalarReduction( device, {
	reduce: [ 'average', 'max', 'min', 'average' ],
	bindings: { wgsl: '@group(1) @binding(0) var hdr: texture_2d<f32>; @group(1) @binding(1) var<storage, read_write> result: array<vec4f, 2>;', entries },
	load: 'fn load( texel: vec2i, layer: u32 ) -> vec4f { let l = max( luma( texel ), 1e-4 ); return vec4f( log( l ), l, l, l ); }',
	finish: 'fn finish( value: vec4f, weight: f32 ) { result[ 0 ] = value; result[ 1 ] = vec4f( exp( value.x ), 0.18 / exp( value.x ), weight, 0.0 ); }',
} );
metering.encode( encoder, { size: [ width, height ], bindGroup } );
new ScalarReduction( device ).encode( encoder, { texture: hdr, output: { buffer } } );  // { value: vec4f, weight: f32 }
