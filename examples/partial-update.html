Partial updates: rect and layers

Paint into level 0 (click and drag on the left image; a scripted brush paints first). Each animation frame writes the dirty texels with writeTexture and updates the chain with rect: every later level rewrites only the texels whose footprint touches the previous level's rewritten ones (2x … 2x+2 at odd sizes), outlined on the right for the last stroke. A second texture gets a full recompute after every update, and the readout checks that the two chains are equal bit for bit.

SPD's rectInfo snaps the rect to 64-texel tiles and recomputes the levels below 64×64 whole; here each level's region is exact, down to the 1×1 (DIVERGES #15). It works with every oddSizes policy. 

device.queue.writeTexture( { texture, origin: [ x, y ] }, data, { offset, bytesPerRow }, [ width, height ] );
downsampler.encode( encoder, texture, { rect: { x, y, width, height } } );  // only what depends on the rect
downsampler.encode( encoder, faces, { layers: [ 2, 1 ] } );                // one face of a 6-layer array
downsampler.encode( encoder, faces, { layers: [ 4, 1 ], rect } );          // a decal on face 4

Readout

    Paint

    One face of a 6-layer array

    A 255 × 255 × 6 '2d-array' texture (cube faces as layers, since WGSL has no cube storage textures). Face 2 is re-baked with layers: [ 2, 1 ], then a decal goes onto face 4 with layers: [ 4, 1 ] and a rect. The other faces are untouched, and every face equals a full recompute.
